[下載 Excel 審核表](../dist/downloads/PAP-business-rules-review.xlsx) · [下載 CSV](../dist/downloads/PAP-business-rules-review.csv)

1. 逐條確認「目前系統做法」及例子。
2. 在 Excel 或 CSV 的「專業結論」填入待確認、同意、需修改或不適用。
3. 需修改時，寫明新的條件、期望結果與例子，交給維護者更新網站規則。

本表記錄目前實作，不代表醫學規則已正確。Excel 中的四個試算結果只驗證比率計算，填寫表格不會直接修改網站。

| 分類-02 | 無法分類的代碼 | 未知代碼保留為未分類，不當成正常。抹片代碼 14 及只有 HSIL 字樣的切片，目前也不直接歸到既有診斷分類。 | 請在「診斷分類」頁確認院內實際使用的代碼是否需要加入。 |
| 判定-01 | 抹切怎麼判定 | 兩邊都有分類且已配對時，依「抹切判定」表決定一致、差異或待專業判定。沒有另行設定的組合預設待專業判定。 | ASC-US 與 CIN1 目前是待專業判定，不自動當成分類一致。 |
| 判定-02 | 未配對與未分類 | 找不到符合條件的切片，顯示未配對。已選用切片但任一邊診斷未分類，顯示未分類。 | 兩種情況分開呈現，不能一起當成分類差異。 |
| 統計-01 | 統計單位 | 以每筆有效抹片為單位，不是以不重複的人數為單位。未知診斷也包含在有效抹片總量中。 | 一人做兩次有效抹片，總量計兩筆。 |
| 統計-02 | 異常與 SIL 定義 | 異常及 SIL 是否納入，取決於「診斷分類」頁的勾選值。未知抹片分類不列入已分類分母。 | ASC-US、ASC-H 現在列為異常，但不計入 SIL；LSIL、HSIL 計入 SIL。 |
| 統計-03 | 品質空白不當良好 | 品質代碼 1、2、3 才列入品質指標分母，其中 3 列為難以判讀。空白或其他代碼不列入品質分母。 | 品質未填的抹片仍可比對，但不能拿來稀釋難以判讀比例。 |
| 統計-04 | 分母為零 | 任何比率的分母為 0 時，不計算；網站顯示 —，不是 0%。 | 只有 ASC、沒有 SIL 時，ASC / SIL ratio 不計算。 |
| 統計-05 | 交叉表計哪些 | 抹切交叉表只計入已配對，且抹片與選用切片都有分類的紀錄。每筆抹片只填一格。 | 已配對但診斷未分類的個案，不填入交叉表，因此交叉表合計可能少於已配對數。 |
| 統計-06 | 提醒門檻 | 目前四項指標都未啟用超標提醒，沒有內建官方合格門檻。 | 專業人員可提出單位自己的提醒值。超過提醒值不代表已判定醫療不合格。 |
| 覆核-01 | 人工註記的作用 | 人工註記「已確認」或「待重閱」不會改寫原始診斷，也不會改變系統計算的一致、差異或統計值。 | 如果希望人工重閱結果回寫統計，需另外定義規則，現行系統未實作。 |
| 覆核-02 | 規則更新後的舊結果 | 新規則只影響下一次比對，舊結果保留當次規則快照，不會自動重新計算。 | 用舊版本做出的報告，不能因後來改了期限就自動變成新版本。 |
