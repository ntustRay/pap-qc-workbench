# 專業規則維護

## 更新流程

1. 開啟「專業規則」，使用五個頁籤維護資料。
2. 修改任何設定，狀態會回到待覆核。更新 `版本`，例如 `2026.11.09-hospitalA.1`。
3. 使用已知結果的去識別測試資料，確認月末、同日、多切片、未知代碼與分母為 0 的情境。
4. 由專業人員填寫覆核者、日期，最後將狀態改成「已由填列的專業人員覆核」。這是本機自我記錄，沒有登入、電子簽章或權限驗證。
5. 套用至此瀏覽器後重新比對。修改規則不會重新計算既有工作。
6. 匯出 `rules.json`，替換網站 `dist/config/rules.json` 後發布。曾套用過本機規則的使用者須還原網站預設規則才能使用新版。

## 可修改項目

| 項目 | 設定方式 | 對統計的影響 |
| --- | --- | --- |
| 追蹤期限 | 1–60 個日曆月 | 決定合格切片窗口與追蹤期滿日 |
| 同日切片 | 勾選是否納入 | 影響抹片當天的切片是否可配對 |
| 配對日期 | 採檢日期／報告日期 | 決定切片必須在哪一日期落入窗口；採檢日仍不得早於抹片 |
| 部位 | 中文／英文完整代碼，逗號分隔 | 只納入設定部位；不使用關鍵字猜測 |
| 多筆切片 | 最早／依自訂優先序 | 每筆抹片只選一筆切片；優先序相同取最早，同日依檢體編號再依列號 |
| 抹片分類 | 代碼清單、名稱、異常及 SIL 勾選 | 未知代碼不列入已分類分母；異常、SIL 影響指標 |
| 切片分類 | 代碼清單、名稱、配對優先序 | 優先序只供選擇切片，不推導診斷一致性 |
| 判定矩陣 | 各抹片分類 × 切片分類 | 一致／差異／待專業判定；未知診斷強制未分類 |
| 統計指標 | 分子、分母條件及診斷代碼限制 | 計數後相除；可顯示百分比或 ratio |
| 欄位名稱 | 每個欄位的別名 | 自動對應院內報表；有歧義要求手動選擇 |

代碼忽略大小寫、前後空白與全半形差異。單個數字會補成兩位（`4` → `04`），識別碼不補零、不轉數字，所以 `001` 與 `1` 不同。

分類 ID 為固定識別碼。頁面新增分類會配置 `CUSTOM...` ID；可自由改名稱及代碼。ASC-US／ASC-H／AGC 的專屬報告以原有分類 ID 聚合；新增分類不會自動加入這些專屬報表，但會出現在分布、交叉表與診斷數量，亦可自訂統計指標。

## 指標條件

分子與分母都以有效抹片計數，可再限制診斷代碼。所有條件以 AND 組合；代碼清單內以 OR 組合。

| 條件 | 意義 |
| --- | --- |
| 全部有效抹片 | 通過基本驗證與去重的 PAS |
| 已分類抹片 | 診斷代碼命中某一分類 |
| 異常分類 | 抹片分類的「異常」有勾選 |
| SIL 分類 | 抹片分類的「SIL」有勾選 |
| 有合格切片 | 有符合識別碼、日期、部位的切片；診斷可能尚未分類 |
| 矩陣可判定 | 判定為分類一致或差異，不含待專業判定 |
| 矩陣差異 | 判定矩陣明確設定為差異 |
| 追蹤已期滿 | 期滿日 ≤ 資料完整截止日 |
| 已期滿且異常 | 上述期滿條件且分類為異常 |
| 已期滿且異常且有切片 | 上述條件且有合格切片 |
| 品質代碼 3 | 難以判讀 |
| 品質代碼 1、2、3 | 排除品質空白或未知代碼 |

自訂提醒值比較的是「畫面顯示值」，例如 5% 填 `5`，ratio 3.0 填 `3`。未設定就不提醒，不使用內建官方合格門檻。

## 規則檔分層

| JSON 區塊 | 用途 |
| --- | --- |
| `schemaVersion` | 格式版本，目前只能是 `1` |
| `profile` | 名稱、版本、覆核者、日期、狀態及備註 |
| `sources` | 專業參考來源及適用範圍 |
| `matching` | 期限、同日、日期、部位、選擇方式 |
| `columns` | PAS／PATH 欄位別名 |
| `smearGroups`、`tissueGroups` | 診斷分類與代碼 |
| `comparison` | 預設待判定與明確矩陣 |
| `metrics` | 宣告式分子／分母計數規則 |

UI 只負責讀寫這份文件，domain engine 負責驗證與運算。不得將 `eval`、JavaScript 字串或病人資料放入規則檔。

預設不將抹片代碼 `14`（OTHER）視為已知正常或異常，也不把只有 `HSIL` 的切片直接當成 `CIN3`。這些會保留為未分類，請依單位實際定義新增或調整分類。
